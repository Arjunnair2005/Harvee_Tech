# AI Usage Documentation

## Purpose

AI assistance was used during the development of this QA automation assessment to support learning, implementation, debugging, and documentation.

## Areas Where AI Was Used

### 1. Test Planning

* Helped organize test scenarios and identify important positive, negative, and boundary cases.
* Assisted in structuring manual test cases and mapping selected scenarios to automation tests.

### 2. Automation Development

* Provided guidance on Python, Selenium WebDriver, pytest, and the Page Object Model.
* Assisted with understanding locators, explicit waits, assertions, and parameterized tests.

### 3. Debugging

* Helped investigate test failures, synchronization issues, and locator-related problems.
* Suggested corrections that were tested by running the automation suite.

### 4. Documentation

* Assisted in preparing project setup instructions, test execution commands, and test coverage documentation.

## Human Review and Validation

AI-generated suggestions were reviewed and incorporated where appropriate. The automation suite was executed to validate the implemented scenarios. The latest recorded test run completed with eight passing tests.

AI assistance does not replace manual verification. Test results, assertions, expected behaviour, and final deliverables must be reviewed before submission.

## Limitations

* The automation covers selected scenarios rather than the complete application.
* Passing automated tests does not guarantee that the application is free of defects.
* Results depend on the test environment, application availability, browser behaviour, and the accuracy of the test assertions.

## Final Responsibility

The assessment submission is reviewed and finalized by the candidate, who is responsible for understanding the test logic, verifying results, and explaining the implementation during the live discussion.
